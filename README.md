## Features

- 3D flip invitation cards for each event
- Live countdown to the Kuhingira
- Downloadable `.ics` calendar files (both dates or each event) with 1-week and 1-day reminders
- WhatsApp and call RSVP actions
- Animated photo marquee, masonry gallery and video moments
- White / burgundy / green theme, reduced-motion support
